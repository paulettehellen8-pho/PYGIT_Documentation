A junior-built, Textual-powered TUI git client — live dashboard, staging, diffs, commits, and conflict resolution, all orbiting one terminal.

01Features

Five core modules, each shelling out to real git via subprocess — no reimplemented git internals, just a friendlier face on top of it.

dashboard.py
$ pygit-tui # status | staged | branches | log | stash ● main 3 ahead, 0 behind
Live Dashboard
Two-column view of status, staged/unstaged files, branches, commit log, and stash — updates as you work.
diff_viewer.py
- old_line = None + old_line = get_diff() @@ -12,7 +12,7 @@
Diff Viewer
Side-panel diff rendering for any selected file, staged or unstaged, before you commit.
commit_modal.py
Commit message: > fix: handle empty stash list [Enter] confirm [Esc] cancel
Commit Modal
A focused modal for writing and confirming commit messages without breaking flow.
command_palette.py
Ctrl+P > stash > switch > merge > pull > push
Command Palette
Quick-access palette for stash, switch, merge, pull, and push without memorizing flags.
git_checker.py
CONFLICT (content): app.py [o] ours [t] theirs [m] manual
Merge Conflict Handler
Surfaces conflicting files during a merge and lets you resolve them without dropping to raw git output.
